# USTP SupplyHub

**Save more. Shop smarter.**  
A campus supply marketplace, live vendor price comparison engine, student group-buying hub, and peer-to-peer reuse network built for **USTP Cagayan de Oro** students.

## Features

- **Home Feed & Campus Essentials**: Semester savings tracker, instant search, barcode lookup simulator, category filters (Pens, Paper, Notebooks, Folders, Art Supplies, Electronics, Printing), and best deals.
- **Smart Price Comparison Engine**: Real-time vendor rate comparison across USTP Student Coop Kiosk, Express Print Hub, Limketkai Express, and University Bookstore.
- **Campus Group Buy Pools**: Live countdown pools with tier progress tracking (`7/10` -> `8/10`), classmate roster, escrow protection, and instant slot reservation.
- **Peer-to-Peer Student Marketplace**: Buy and sell secondhand textbooks, scientific calculators, drafting tools, and lab coats with condition grading, wishlist bookmarking, and direct campus meetup chat.
- **Sell Item Flow**: Full item listing composer with photo slots, condition chips, student price savings preview, and safe on-campus meetup zones.
- **Cart & Express Campus Checkout**: Live quantity steppers, Free On-Campus Pickup vs. Dorm Runner delivery, GCash / Maya / Cash on Pickup options, and instant order confirmation codes.
- **My Campus Orders**: Multi-step pickup tracker, live Group Buy pool progress, receipt viewer, and interactive Kiosk Pickup QR Code pass.
- **Student Profile & Verification**: USTP Student ID verification card, Campus Pass ID modal, campus sustainability impact summary, and account preferences.

## Tech Stack

- **React 19** + **TypeScript**
- **Vite**
- **Tailwind CSS v4**
- **Lucide React** icons

## Getting Started
